# Шлюз Захищеної Взаємодії «ІС ефект» (API Gateway)

Це спеціалізований компонент безпеки (API Gateway), розроблений на базі Node.js та Express для інформаційної системи «ІС ефект». Шлюз виступає інтелектуальним фільтром між зовнішніми компонентами та компонентами обробки даних, забезпечуючи парсинг кастомного протоколу, семантичну валідацію, контроль доступу та криптографічний захист запитів.

## Основні можливості

- **Обробка кастомного протоколу:** парсинг та валідація текстових повідомлень формату `SENDER#TARGET#METHOD#FIELD#PARAMS`.
- **Контекстні шаблони:** динамічна маршрутизація та перевірка запитів залежно від бізнес-шаблону (`rating` або `general`).
- **Контроль доступу:** розмежування прав між студентами та викладачами, жорсткий контроль лімітів виставлення балів.
- **Криптографічний захист:** генерація службових заголовків (`Timestamp`, `Nonce`, HMAC-SHA256 підпис) для захисту сервера від прямого обходу шлюзу.
- **Аудит та журналювання:** асинхронний запис усіх етапів обробки запиту у файл `gateway.log`.
- **Reverse Proxy:** підтримка проксіювання класичного HTTP-трафіку для інтеграції зі сторонніми сервісами.

## Архітектура проєкту

Проєкт побудовано за модульним принципом (**Separation of Concerns**).

### `src/controllers/`

Керування життєвим циклом запитів:

- `gateway`
- `proxy`

### `src/services/`

Ізольована бізнес-логіка:

- `parser.service.js` - синтаксичний розбір протоколу.
- `base-validator.service.js` / `template-validator.service.js` - багаторівнева перевірка даних.
- `access-control.service.js` - перевірка ролей та лімітів.
- `forwarder.service.js` - криптографічний підпис та відправка на бекенд.
- `logger.service.js` - система аудиту.

## Встановлення та запуск

### Попередні вимоги

- Node.js (v16 або вище)
- npm

### Інструкція

#### 1. Клонуйте репозиторій

```bash
git clone <URL_вашого_репозиторію>
cd gateway-server
```

#### 2. Встановіть залежності

```bash
npm install
```

#### 3. Створіть файл `.env` у корені проєкту та налаштуйте змінні середовища

_(дивіться `constants.js` для деталей)_

```env
PORT=8080
GATEWAY_SECRET_KEY=your_super_secret_key
BACKEND_TIMEOUT_MS=15000
```

#### 4. Запустіть сервер

```bash
npm start
```

## Тестування

Проєкт покритий модульними тестами (**Unit Tests**) з використанням фреймворку Jest. Тести перевіряють логіку контролерів, парсера, валідаторів та системи логування через механізм mock-об'єктів.

Щоб запустити тести:

```bash
npm test
```

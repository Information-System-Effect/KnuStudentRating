Module: AccessControlService

Сервіс семантичного контролю доступу (RBAC). Реалізує Матрицю Контролю Доступу, перевіряє рольові ліміти (5 балів для студентів, 20 для викладачів) та блокує спроби зміни недозволених сутностей.

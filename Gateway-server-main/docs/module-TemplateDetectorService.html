Methods

(inner) detectGatewayTemplate(parsed) → {string}

Визначає логічний шаблон gateway-запиту. Логіка розпізнавання: 1. Якщо запит адресований конкретному користувачу (targetUserCode !== "_"). 2. Якщо метод GET або DELETE і поле міститься у списку рейтингових. 3. Якщо метод PUT або PATCH і ВСІ поля у складеному масиві змін (changes) належать до рейтингових категорій. Якщо умови виконуються — повертається контекст "rating". В іншому випадку — повертається "general" (наприклад, запит на список студентів).

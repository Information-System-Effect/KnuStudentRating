Module: AppConfig

Файл конфігурації Express-застосунку. Налаштовує middleware для обробки текстових запитів (text/plain) та підключає маршрути для внутрішнього протоколу і proxy-переадресації.

Головний файл конфігурації Express-застосунку шлюзу. Призначення: - створити екземпляр Express; - підключити маршрути gateway для обробки внутрішнього текстового протоколу; - підключити proxy-контролер для пересилання звичайних HTTP-запитів на backend; - визначити порядок обробки запитів у межах шлюзу.
